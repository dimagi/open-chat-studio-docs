# API access to OCS chatbots

Using the API allows you to interact with your chatbot programmatically. This comes in especially useful when you're using a third-party system to evaluate your chatbot. API access is enabled by default for all chatbots.

To get started, you will need an API key, which you can generate by going to your [profile page][profile-page].

See the [API documentation][api-docs] for more details.

[profile-page]: https://openchatstudio.com/users/profile/
[api-docs]: https://openchatstudio.com/api/docs/
