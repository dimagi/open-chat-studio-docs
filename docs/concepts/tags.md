# Tags

Tags are labels applied to chats and messages to categorize and organize interactions. For instance, tags can be used to mark messages that require follow-up or to segment participants based on their interactions.

Tags can be created using the “Manage Tags” section.

Tag names are limited to 100 characters.
The **Message Tag** field on pipeline nodes rejects longer values with a validation error, so shorten the tag to fix it.
Longer tags added by a router node (**Tag Output Message**) or the Python node `add_message_tag` function are cut to 100 characters when saved.

![Manage Tags section showing options to create and edit tags](../assets/images/tags_manage.png)

## Types Of Tags

There are 3 types of tags.

### System tags  
These are tags generated by the system, such as those used in [multi-prompt architectures](../how-to/workflow_cookbook.md#split-a-chatbot-into-multiple-smaller-chatbots) to differentiate between parent and child chatbots.

### Session tags  
These tags are manually added to [sessions](sessions.md).

### Message tags  
These tags are manually added to specific messages within a participant session.
