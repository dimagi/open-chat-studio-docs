# Feature Flags

The **Feature Flags** page in Team Settings is where Team Admins switch experimental Open Chat Studio (OCS) features on and off for their team.

## What a feature flag is

A feature flag is a switch that makes a new or unfinished feature visible to your team.
OCS puts some features behind a flag so teams can opt in before the feature is finished and available to everyone.

The description beside each checkbox names the feature and how finished it is.
An `(alpha)` or `(beta)` marker means parts of the feature may be incomplete or may change.
Turning one on can expose screens that are still being worked on.

Only the flags your team is allowed to manage appear here.
[Evaluations](../evaluations/index.md), for example, is a feature your team can turn on for itself.
